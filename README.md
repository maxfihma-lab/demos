# Fihma Advisory demos

Public GitHub Pages site for personalized, static AI booking demos used in Fihma Advisory cold outreach.

- Site: https://maxfihma-lab.github.io/demos/
- Sample: https://maxfihma-lab.github.io/demos/sample/

Each `/<slug>/` folder is a one-page mock for a single business. Nothing on these pages books appointments or sends messages.

## Enable Pages (one-time)

If the site 404s, turn Pages on once:

1. Open https://github.com/maxfihma-lab/demos/settings/pages
2. Under Build and deployment → Source, choose **Deploy from a branch**
3. Branch: **main**, folder: **/ (root)**
4. Save. Wait about a minute, then open the site URL above.

## Local template

Built with `/workspace/fihma_demo_template/` on the outreach box. See that folder's README for publishing a new demo.
