# Fihma Advisory demos

Public GitHub Pages site for personalized, static AI booking demos used in Fihma Advisory cold outreach.

- Site: https://maxfihma-lab.github.io/demos/
- Sample: https://maxfihma-lab.github.io/demos/sample/

Each `/<slug>/` folder is a one-page mock for a single business. Nothing on these pages books appointments or sends messages.

Built with the local template at `/workspace/fihma_demo_template/` on the outreach box.
